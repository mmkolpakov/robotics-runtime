# Published CLI consumer inputs

Use these exact files with [the first-result guide](../../../../docs/first-result.md)
and the published contracts 0.20.0 / harness 0.21.0 pair. The documentation reader
exports them as `consumer-inputs.zip`, with source revision and per-file SHA-256
in `manifest.json`. PyPI installation alone does not install the examples.

`scenario-input.json` is an authored synthetic scenario; `runtime-template.json`
contains explicitly synthetic runtime facts. `produce.py` uses public contracts
writers and MCAP 1.4.0 to create the exact scenario, runtime, run context, synthetic
OTLP JSON-lines stream, one UInt64 MCAP recording, recording summary and finalized
evidence index. It has no repository or test support imports.

```bash
python -m pip install "robotics-runtime-contracts[mcap]==0.20.0" \
  robotics-acceptance-harness==0.21.0 mcap==1.4.0
python produce.py --output inputs
```

Choose a new output directory per production. The producer refuses an existing
directory. Evidence links use absolute paths to the generated source files; retain
those files in place for evaluation. File sizes and digests are derived from the
generated bytes rather than supplied placeholders.

The expected offline outcome is `incomplete`, exit `1`, with JSON and JUnit.
The synthetic runtime identities and graph declarations do not qualify a live
execution, image or simulator. See the guide for all commands, file ownership,
missing coverage and a byte-integrity refusal.
